1. Create virtual environment using the requirements.txt file.
2. make sure to update config.py with the correct keys for OpenAI and Telegram. Review all other parameters and set according to your preferences.
3. start application with python tgbot.py
4. in Telegram start a private conversation with the bot you have chosen (whose key you use)
5. to start the document generation process enter "/scaffold" into the Telegram prompt.
